# Careerways — System Administration Career Pathways

A responsive career portfolio introducing the system administration career path, key roles, skills, and tools. Built with React and Vite.

The landing hero uses a custom, configurable `GridMotion` background component. Its image tiles load from Unsplash, so an internet connection is needed to display those photos.

## Run locally

```sh
npm install
npm run dev
```

## Verify and build

```sh
npm run lint
npm run build
```

## Personalize the developer profile

Update the name, program, career interest, and goal in the `profile-details` section in `src/App.jsx` before submitting the portfolio.

To customize the hero collage, edit the `gridItems` list in `src/App.jsx` and adjust the `GridMotion` props there.
